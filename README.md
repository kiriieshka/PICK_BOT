# ПИК — Basketball Challenge Bot v1.2

Telegram-бот для карточной баскетбольной игры на одном телефоне.

## Режимы
- Игра до 5 очков — карточки возвращаются после каждой попытки; игра заканчивается при 5 очках.
- Игра до 15 очков — карточки возвращаются после каждой попытки; игра заканчивается при 15 очках.
- Игра до 50 очков — после каждой попытки карточка удаляется; игра также заканчивается при достижении 50 очков.

## Меню Telegram
Вместо Reply Keyboard используется стандартное меню команд Telegram. После запуска у бота в кнопке «Меню» доступны:
- 🎮 Новая игра — `/newgame`
- 📊 Статистика — `/stats`
- 🏆 Общая статистика — `/overall`

Рестарт не добавлен в меню команд: он остаётся отдельной inline-кнопкой после завершения/внутри сценария подтверждения рестарта.

## Запуск локально
1. Создайте `.env` рядом с `main.py`.
2. Укажите `BOT_TOKEN`.
3. Для запуска без MySQL оставьте `DB_ENABLED=false`.
4. Активируйте venv и установите зависимости:
   `python -m pip install -r requirements.txt`
5. Запустите:
   `python main.py`

История при отключённой БД хранится в `data/history.json`.
