# Магазин + игровой бот

Игровой бот и магазин используют одну PostgreSQL-базу.

Магазин создаёт запись `activation_codes` после успешной оплаты электронной версии.
Игровой бот проверяет этот код при активации и после успешной активации записывает пользователя
в `activated_users`.

Для обоих проектов должна быть указана одна и та же:

`DATABASE_URL=postgresql://...`

Также для обоих проектов должно быть:

`DB_ENABLED=true`

Логика игры не изменена; изменён только способ хранения активационных ключей.
